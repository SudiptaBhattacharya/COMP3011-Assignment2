# AI assistance record

AI tools were used as a supporting aid during development of this assignment. Their role was to help clarify requirements and explain implementation choices; the project work and final decisions were reviewed in the context of the assignment and the existing code.

## Areas where AI assistance helped

- Breaking down the specification into implementation and verification tasks.
- Explaining command-line parsing, JavaFX playback flow, frame processing, and concurrency concepts.
- Reviewing code paths for likely issues, including option parsing, effect ordering, frame ownership, task ordering, cancellation, and shutdown.
- Suggesting fixes and helping diagnose Maven configuration, plugin, parameter, and build problems.
- Helping plan and interpret automated checks, manual playback checks, and documentation.

Suggestions were treated as guidance. Code and outputs still needed to be checked against the project, its requirements, and test results; AI assistance does not establish that a feature works or that a performance improvement has been measured.

## Models and tools

OpenAI Codex was used through sessions that may use different GPT-6 family models. Earlier project material also credits GPT-5.6 Terra. The exact model can vary between sessions, so this record does not attribute every suggestion to a single model. Maven, the Java compiler, project tests, and manual checks were used separately to inspect the resulting work.
